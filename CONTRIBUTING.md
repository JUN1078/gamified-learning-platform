# Contributing to LearnHub

Thank you for your interest in contributing to the LearnHub gamification platform!

## Development Setup

1. Follow the [SETUP.md](SETUP.md) guide
2. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Code Style

### TypeScript
- Use TypeScript for all new code
- Define proper interfaces and types
- Avoid `any` types when possible

### React Components
- Use functional components with hooks
- Keep components small and focused
- Use meaningful component and variable names

### Backend
- Follow RESTful API conventions
- Validate all inputs
- Handle errors gracefully
- Add JSDoc comments for complex functions

## Commit Messages

Use clear, descriptive commit messages:
```
feat: Add peer review dashboard
fix: Resolve radar chart rendering issue
docs: Update API documentation
refactor: Simplify card collection logic
```

## Pull Request Process

1. Update documentation if needed
2. Test your changes thoroughly
3. Ensure all tests pass
4. Submit PR with clear description
5. Link any related issues
